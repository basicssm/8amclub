# 8AM CLUB

Next.js (App Router) + TypeScript. Brand site + shop.

```
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

- Products: `lib/products.ts`
- Product photos: `public/products/` (first image of each product, second shows on hover)
